## 共用常數：localStorage Keys

| Key | 用途 | 預設值 |
|---|---|---|
| `v11_preorder_kws` | 預購關鍵字 | `''` |
| `v11_scan_pages` | 掃描深潛頁數 | `'1'` |
| `v11_batch_subj` | 異常單公版主旨 | DEFAULT_EMAILS.DUP_CANCEL.subject |
| `v11_batch_body` | 異常單公版內文 | DEFAULT_EMAILS.DUP_CANCEL.body |
| `v11_resume_logistics` | 跨頁續航旗標 | (未設) |
| `v11_resume_payload` | 跨頁續航資料 | (未設) |
| `v11_last_kanban_open` | 上次看板是否開著 | `'0'` |
| `v11_preorder_tab` | 預購歸類分頁 | `'暫存'` |
